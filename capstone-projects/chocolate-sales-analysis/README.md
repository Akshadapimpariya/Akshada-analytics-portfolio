# 🍫 Chocolate Sales Performance Analysis: End-to-End Data Solution

## Project Overview
This project provides a comprehensive analysis of global chocolate sales data (400,000+ records) spanning from 2022 to 2025. It demonstrates a complete data lifecycle: **Data Cleaning (Python)**, **Advanced Analytical Querying (SQL)**, and **Executive Reporting (Power BI)**.

## 🚀 Key Features
- **Data Engineering:** Automated the cleaning of 400k+ rows, handling currency formatting, missing values, and date transformations using Pandas.
- **Advanced SQL Analytics:** Implemented window functions to track sales "acceleration," rolling averages, and dense ranking for product revenue.
- **Business Intelligence:** Developed a Power BI dashboard (PBIX) to visualize shipment density, salesperson consistency, and geographic performance.

## 🛠️ Tech Stack
- **Python (Pandas, Seaborn, Matplotlib):** Exploratory Data Analysis (EDA) and visualization.
- **SQL (PostgreSQL/Standard SQL):** Data transformation, outlier detection, and complex aggregations.
- **Power BI:** Interactive dashboarding.
- **Dataset:** 400,000 transaction records including Sales Person, Country, Product, and Amount.

## 📊 Business Insights Derived
- **Top Performer:** Identified **Beverie Moffet** as the lead sales person in India and **Marney O'Breen** in the USA by total revenue.
- **Seasonal Trends:** Discovered that January consistently yielded the highest sales across multiple years (2022, 2024, 2025).
- **Sales Consistency:** Analyzed monthly sales variability to identify **Dennison Crosswaite** as the most consistent salesperson (lowest standard deviation).
- **Product Strength:** Determined that **Baker's Choco Chips** generated the highest average revenue per box shipped.
- **Geographic Concentration:** Found that over **50% of total revenue** is generated by the top 3 countries alone.

## 📂 File Structure
- `Chocolate_Sales.csv`: The raw transactional dataset.
- `chocolate_sales.ipynb`: Python notebook for EDA and statistical analysis.
- `chocolate_sales.sql`: SQL script for database schema and advanced analytical queries.
- `chocolate_sales.pbix`: Power BI report file.
